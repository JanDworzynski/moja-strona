# Moja strona

Prosta strona z nagłówkiem, stopką, imieniem i nazwiskiem oraz przyciskiem.

- `index.html` - strona na GitHub Pages, przycisk uruchamia skrypt z pliku `skrypt.js`
- `php/index.php` - wersja z PHP, przycisk dodaje wpis do bazy MySQL (MariaDB)
- `baza/baza.sql` - tabela `wpisy`
- `.devcontainer` - ustawienia Codespaces (PHP, baza, phpMyAdmin)
- `motyw.sh` - instalacja motywu darkwolf do phpMyAdmin

Strona PHP: port 80, phpMyAdmin: port 8081 (login: student, hasło: student)
